# А что у нас в Go

В языке Go (Golang) подход к структурам данных сочетает в себе прагматизм, высокую производительность и простоту. Тут есть мощные базовые типы и гибкие механизмы для создания собственных.


**Массивы (Arrays)**

Массивы в Go — это фундамент, но на практике они используются редко. Их главные особенности:
- Фиксированный размер. Размер является частью типа (например, [5]int и [10]int — это абсолютно разные типы).
- Передача по значению. Когда вы передаете массив в функцию, Go полностью копирует его содержимое в памяти.


**Срезы (Slices)**
Срезы — это «динамические массивы» и, пожалуй, самый часто используемый инструмент в Go. На самом деле срез сам по себе не хранит данные, он лишь ссылается на базовый массив (underlying array).

Внутри срез представляет собой структуру из трех элементов (дескриптор среза):
- Указатель (Pointer) на первый элемент базового массива, с которого начинается срез.
- Длина (Length) — количество элементов, которые сейчас есть в срезе (len()).
- Емкость (Capacity) — максимальное количество элементов, которое срез может вместить без выделения новой памяти (cap()).

Когда вы превышаете cap (например, через append), Go автоматически выделяет новый, более просторный массив в памяти, копирует туда старые данные и переключает указатель.


**Карты / Хеш-таблицы (Maps)**
Карта (map) — это встроенная ассоциативная структура данных (ключ-значение).
- Поиск, вставка и удаление происходят в среднем за O(1).
- Порядок не гарантируется. Go намеренно рандомизирует итерацию по карте, чтобы разработчики не полагались на порядок элементов.
- Потокобезопасность: стандартные карты небезопасны для конкурентного чтения и записи. Если несколько горутин пишут в одну карту одновременно, программа упадет с паникой.


**Структуры (Structs)**

Структура — это пользовательский тип данных, объединяющий поля разных типов. В Go нет классов, поэтому структуры (вместе с методами) выполняют их роль.
Анонимные поля (Встраивание / Embedding): Вместо классического наследования Go использует композицию. Вы можете встроить одну структуру в другую, и поля внутренней структуры станут доступны напрямую.


**Каналы (Channels)**

Каналы обычно рассматривают как инструмент конкурентности, но технически внутри Go (в рантайме) канал — это сложная структура данных (hchan), представляющая собой очередь FIFO (First In, First Out), защищенную мьютексом, со списками заблокированных горутин (на чтение и на запись).

Они используются для безопасного обмена данными между горутинами без явного использования блокировок со стороны программиста


**Структуры из стандартной библиотеки (container/...)**

Если встроенных типов мало, в стандартной библиотеке Go есть пакет container, предоставляющий классические динамические структуры:
- container/list: Двусвязный список (Doubly Linked List). Полезен, если нужно часто вставлять/удалять элементы из середины.
- container/heap: Куча (приоритетная очередь). Позволяет построить min-heap или max-heap на основе любого типа, реализующего интерфейс sort.Interface.
- container/ring: Кольцевой буфер (Circular List). Список, у которого следующий элемент за последним — это первый.


**Передача по ссылке vs по значению:** 
- Срезы, карты и каналы — это "ссылочные типы" (под капотом содержат указатели). Передавая их в функцию, вы модифицируете исходный объект. 
- Массивы и структуры передаются копированием (по значению), если не использовать указатели (*Struct).

**Аллокация памяти:** 
- Старайтесь заранее инициализировать срезы и карты с известной емкостью make([]int, 0, 100). Это убережет программу от лишних перевыделений памяти и сборщика мусора.
